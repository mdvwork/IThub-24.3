# Тестирование. Проектирование тестов

Курс для 3-го курса СПО (09.02.07): **56 академических часов, 100 баллов**. Это первая публикация материалов: программа курса, теория трёх базовых тем, готовая практическая работа 1 и план работ 2–10. Практика строится вокруг существующих проектов и API.

## Где что находится

- [Программа на 56 часов и 100 баллов](assessment/plan_56h_100pts.md) — последовательность, результаты и оценивание.
- [Проверенные кандидаты для практики](resources/candidates.md) — источники, запуск, ограничения.
- [Практическая работа 1](practice/01_requirements_and_tests.md) — готовое задание для студентов.
- [Теория](theory/README.md) — понятия, методы и проектирование по моделям.

## Принцип прохождения

В каждой работе студент сначала формулирует проверяемое правило и выбирает тестовые данные, затем выполняет проверку, объясняет результат и сдаёт артефакты. Скопированный тест без объяснения ожидаемого результата не засчитывается. AI можно применять для поиска пропусков и обсуждения идей; каждое утверждение из его ответа нужно сверить с требованиями и поведением программы.

Работы 2–10 пока описаны на уровне программы; полное задание опубликовано для работы 1. Распределение часов и баллов в программе проектное и может быть скорректировано после сверки с образовательной платформой.
