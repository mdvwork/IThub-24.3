# Реальные источники для практики

Проверено по первичным страницам проектов и их документации **10.10.2026**. «Запуск проверен» означает локальный прогон в этой рабочей папке; остальные варианты пока подтверждены документацией и требуют отдельной пробной установки перед выдачей студентам. Предпочтительный путь курса: **Gilded Rose → JSONPlaceholder/httpbin → Flaskr → TodoMVC**. JSON Server нужен как локальная альтернатива для проверок, меняющих данные.

## Решение по выбору

Основные обязательные работы можно выполнить на Gilded Rose, Flaskr, TodoMVC и одном API. JSONPlaceholder и httpbin позволяют начать API без настройки; JSON Server даёт локальный CRUD при наличии Node.js. Эти источники не обещают намеренных дефектов во всех частях приложения: студент оценивает поведение по проверяемому правилу и фиксирует реальный результат. Не выдавать случайное падение внешнего сервиса за дефект продукта.
