# Инструменты мастерской

## 1. Минимальный набор

Python 3.10+, привычный редактор и встроенный `unittest`. Никакого сервера, базы или дополнительного сервиса. Команды запускайте из папки `project`. Если нет команды `py`, заменяйте `py -3` на `python` либо путь к вашему Python.

```powershell
py -3 main.py
py -3 -m unittest discover -s tests -v
```

Первое запускает текстовое меню, второе выполняет тесты. Результаты меню и тестов не используют общее состояние: это разные запуски программы.

## 2. Пять полезных операций

| Задача | Инструмент | Что делать |
| --- | --- | --- |
| Воспроизвести неисправность | Текстовое меню | Сбросить данные, повторить конкретную последовательность, записать числа |
| Выразить ожидание | `unittest` | Подготовить состояние, вызвать действие, сравнить ответ/остаток/записи |
| Понять падение | Вывод теста | Найти имя теста, строку утверждения, факт и ожидание |
| Посмотреть промежуточные данные | `print` или знакомый отладчик редактора | Посмотреть вход, ответ и состояние перед ошибкой; не менять ожидание |
| Убедиться, что исправление не сломало соседнее | Повторный запуск всего набора | Проверить новые тесты и готовый стартовый пример |

## 3. Минимальный синтаксис

```python
state = new_state()
result = issue(state, "mic", "1")
self.assertTrue(result["ok"])
self.assertFalse(result["ok"])  # выбирайте True ИЛИ False по требованию
self.assertEqual(state["stock"]["mic"], 2)
self.assertEqual(len(state["loans"]), 1)
```

Это словарь команд, не один готовый тест: одновременно ожидать `True` и `False` для одного ответа нельзя.

Для возврата после успешной выдачи используйте ID из ответа:

```python
loan_id = result["loan_id"]
returned = return_loan(state, loan_id)
```

Чтобы проверить **отсутствие любых изменений** при отказе:

```python
from copy import deepcopy
before = deepcopy(state)
# Здесь вызовите действие, которое по требованию должно быть отклонено.
self.assertEqual(state, before)
```

Обычное `before = state` не создаёт снимок: обе переменные указывают на один изменяемый объект.

## 4. Типовые проблемы запуска

- `No module named mediapolka` — проверьте папку запуска: нужна `project`.
- `Ran 0 tests` — проверьте имена `test_*.py`, методы `test_...`, отступы и наследование от `unittest.TestCase`.
- `SyntaxError` или `IndentationError` — сначала исправьте синтаксис теста. Это ещё не найденная неисправность программы.
- `KeyError: loan_id` — посмотрите `result`: не пытайтесь вернуть выдачу, если её создание было отклонено.
- Тест проходит поодиночке, но мешает другим — проверьте независимость: каждый тест начинает со своего `new_state()`.

## 5. Границы технической помощи

Можно обращаться за помощью, если не запускается Python, не обнаруживаются тесты, непонятен синтаксис утверждения или работа редактора. Преподаватель может объяснить такой вопрос на отдельном нейтральном примере.

Выбор правил, тестовых данных, последовательностей, подозрительных строк и исправлений остаётся за вами. Карточек с направлениями поиска и готовых неисправных примеров для разбора в этом занятии нет.
