# Запуск программы и проверок

Нужен Python 3.10 или новее. Внешних библиотек и установки пакетов нет: `unittest` входит в Python. Интернет во время занятия не нужен. Используйте VS Code, PyCharm или другой уже знакомый редактор.

Откройте терминал **в этой папке `project`**, где лежат `main.py` и `mediapolka.py`.

```powershell
py -3 --version
py -3 main.py
```

Запуск всех учебных тестов из этой же папки:

```powershell
py -3 -m unittest discover -s tests -v
```

Если команда `py` отсутствует, замените `py -3` на `python` или полный путь к установленному Python. Выберите один работающий способ и используйте его во всех командах. Создавать окружение и устанавливать Pytest для этого пакета не требуется.

Первоначально должен обнаружиться **1 тест**, он проходит. Если обнаружено 0, проверьте папку запуска и имена файлов `test_*.py`. Прохождение единственного примера не означает исправность программы.

## Файлы

- `mediapolka.py` — логика программы, здесь нужно искать и исправлять нарушения требований.
- `main.py` — готовое текстовое меню для ручного исследования; его менять не требуется.
- `tests/test_start.py` — один проходящий пример синтаксиса, не изменяйте его.
- `tests/test_student.py` — ваши тесты, сюда добавляйте методы `test_...`.

Данные существуют только в памяти. Каждый новый запуск программы и вызов `new_state()` создаёт чистый комплект. В меню команда 3 делает сброс. Файлов, базы, сети и интерфейса сайта нет.

## Сохранение доказательств

До исправления, когда собственные тесты уже обнаруживают ошибки:

```powershell
py -3 -m unittest discover -s tests -v 2>&1 | Tee-Object before.txt
```

После исправления:

```powershell
py -3 -m unittest discover -s tests -v 2>&1 | Tee-Object after.txt
```

Красный вывод до исправления здесь ожидаем: тест выявил несоответствие. Файлы сохраните раздельно; не перезаписывайте `before.txt` после починки. Запуск с `Tee-Object` — для сохранения вывода, итог успешности смотрите в строках `OK` или `FAILED` самого `unittest`.
