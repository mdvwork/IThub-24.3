# Мастерская: исследовать, проверить, починить

Вам досталась неисправная «Медиаполка». Программа запускается, но часть действий выполняет неправильно. Ваша задача — обнаружить нарушения требований собственными тестами и исправить программу.

1. Прочитайте [требования](02_Проект.md).
2. Откройте папку `project` в редакторе и выполните [команды запуска](project/README.md).
3. Изучите [теорию](01_Теория.md) и [инструменты](05_Инструменты.md). Преподаватель покажет запуск и синтаксис проходящего теста. Все неисправности и способы их воспроизведения ищите самостоятельно.
4. Выполните [КТ](03_КТ.md), записывая решения в [короткий протокол](04_Шаблон.md).

Главное правило: **сначала тест обнаруживает ошибку, потом вы исправляете код**. Изменить программу наугад и показать только финальное «всё зелёное» недостаточно.

Материалы открываются в обычном редакторе. Интернет, аккаунты и установка дополнительных библиотек не нужны. HTML-страниц в комплекте нет.
